# AGENTS.md

## Stack & Environment
- **Monorepo Structure**: Separate `frontend/` and `backend/` packages (no root package.json).
- **Frontend**:
  - React `19.2.0`, TanStack Start `1.168.26`, TanStack Router `1.170.16`, TanStack React Query `5.101.1`
  - Vite `8.0.16` (preset: `cloudflare-module` with Nitro `3.0.260603-beta`), Tailwind CSS `4.2.1` (`@tailwindcss/vite`)
  - Radix UI primitives, Framer Motion `12.42.2`, Lucide React `0.575.0`, Zod `3.24.2`
  - TypeScript `5.8.3`, ESLint `10.8.0`, Prettier `3.7.3`
- **Backend**:
  - Next.js `14.2.15` (App Router, standalone Node API server)
  - TypeScript `5.6.3`, Python 3 + `yt-dlp` + FFmpeg (configured via `backend/Dockerfile` and `backend/requirements.txt`)
- **Deployment**:
  - Frontend: Vercel / Nitro Cloudflare worker preset
  - Backend: Render Docker Web Service (`Dockerfile`)

## Verified Commands

### Frontend (`cd frontend`)
- **Dev**: `npm run dev` (starts Vite dev server at `http://localhost:3000`)
- **Build**: `npm run build` (outputs SSR bundle to `.output/`)
- **Type-check**: `npx tsc --noEmit`
- **Lint**: `npm run lint` (runs `eslint .`)
- **Format**: `npm run format` (runs `prettier --write .`)
- **Test**: None configured

### Backend (`cd backend`)
- **Dev**: `npm run dev` (starts Next.js API at `http://localhost:8080`)
- **Build**: `npm run build` (`rm -rf .next/cache && next build`)
- **Type-check**: `npm run typecheck` (`tsc --noEmit`)
- **Start**: `npm run start` (`next start`)
- **Lint**: `npm run lint` (*Note: `next lint` prompts interactively unless ESLint config is created in `backend/`*)
- **Test**: None configured

## Code Style & Conventions
- **TypeScript**: Strict mode enabled across both packages.
- **Path Aliasing**:
  - Frontend: `@/*` maps to `./src/*`
  - Backend: `@/*` maps to `./*`
- **Routing**: File-based routing via TanStack Router (`frontend/src/routes/`). `frontend/src/routeTree.gen.ts` is auto-generated; do NOT edit manually.
- **UI Components**: Headless Radix UI + Tailwind CSS styled with `cn()` utility (`clsx` + `tailwind-merge`) in `frontend/src/lib/utils.ts`.
- **API Communication**: Backend uses Next.js Route Handlers (`backend/app/api/**/route.ts`). Client calls use `frontend/src/lib/api.ts` with explicit 35s timeout abort signals.
- **Server Separation**: TanStack Start requires server-only code to use `*.server.ts` or `@tanstack/react-start/server-only`.

## Sensitive / Protected Areas (Do Not Modify Casually)
- `frontend/src/routeTree.gen.ts`: Auto-generated by TanStack Router plugin.
- `backend/Dockerfile` & `backend/requirements.txt`: Defines system dependencies (Python, `yt-dlp`, `ffmpeg`) for Render deployment.
- `backend/middleware.ts`: Controls CORS origins and preflight headers; changes can cause browser cross-origin failures.
- `backend/lib/media-fetcher.ts`, `backend/lib/ytdlp.ts`, `backend/lib/cobalt.ts`: Core extraction logic orchestrating Cobalt API and yt-dlp fallback pipelines.
- `frontend/src/lib/api.ts`: API client interfacing with `VITE_API_URL`.

---

## Known Gotchas & Constraints
- **Backend Lint**: `next lint` prompts interactively in `backend/` because ESLint is not configured in backend. Use `npm run typecheck` for validation.
- **Host Tools for Local YouTube Downloads**: Local backend development requires `yt-dlp` and `ffmpeg` installed on the host machine (`brew install yt-dlp ffmpeg`).
- **CORS Configuration**: `FRONTEND_ORIGIN` must match the frontend origin in production (supports comma-separated list).
- **Vite Build-time Env**: `VITE_API_URL` is baked at build time into the frontend bundle; updating backend host requires frontend rebuild.
